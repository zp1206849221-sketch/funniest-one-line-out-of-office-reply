# Funniest One-Line Out-of-Office Reply

A single out-of-office auto-reply line that keeps the real away-message
skeleton — out of office, a return date, and what happens to urgent mail —
with one twist at the end: urgent emails will be answered on return, in the
exact order they stopped being urgent.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
Python standard library only.
